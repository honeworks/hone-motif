| Example | What it shows |
|---|---|
| [quickstart.py](quickstart.py) | search the library, build the placement prompt's parts, check a reply and repair it (design §7) |
| [brand.py](brand.py) | draw an asset in a channel's own colours and fonts over a theme; the font check and the contrast warning (design §4.3) |
